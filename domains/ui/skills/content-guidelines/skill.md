# Content guidelines

Encodes the MetaMask Content Design Style Guide for AI-assisted development.
Covers capitalization, punctuation, voice and tone, per-component patterns,
and the approved terminology list.

## When to use

- Writing or reviewing user-facing strings in component stories, constants, READMEs, or locales
- Checking whether a string uses correct sentence case vs. title case
- Reviewing button labels, headers, banners, toasts, modal copy, and error messages
- Auditing terminology (gas fee → network fee, dapp → site, etc.)

## Out of scope

- Code style, TypeScript conventions, or component API decisions (see `ui-development`)
- Marketing or external comms copy
