# Deeplink Routes (Extension)

Authoring and reviewing extension deeplink routes is documented in the extension repository,
at `docs/deeplink-route-authoring.md`. It covers the ownership split with
`@MetaMask/extension-security-team`, the interstitial rule, the extension's own trusted
origins and canonicalization, and the four steps of adding a route.

It lives there rather than here because its audience is an extension engineer reading the
repository, not only an agent with this skill installed. This file is a pointer so the two do
not diverge.
